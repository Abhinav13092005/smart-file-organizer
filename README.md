# 📂 Smart File Organizer

A web-based file organizer built using **Python and Flask** that automatically categorizes uploaded files into different folders based on their file type.

## 🚀 Live Demo

https://smart-file-organizer-qux6.onrender.com

## 🛠️ Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* OS Module

## ✨ Features

* Upload multiple files at once
* Automatically detect file types
* Organize files into categories
* Supports Images, Documents, Audio, Videos, Archives and Others
* Simple and responsive web interface
* No database required

## 📁 File Categories

| Category  | Examples                                  |
| --------- | ----------------------------------------- |
| Images    | JPG, PNG, GIF, WEBP, SVG                  |
| Documents | PDF, DOC, DOCX, TXT, XLS, XLSX, PPT, PPTX |
| Audio     | MP3, WAV, AAC, OGG, FLAC                  |
| Videos    | MP4, AVI, MKV, MOV, WMV, WEBM             |
| Archives  | ZIP, RAR, 7Z, TAR, GZ                     |
| Others    | Other file types                          |

## 💻 Run Locally

```bash
git clone https://github.com/Abhinav13092005/smart-file-organizer.git
cd smart-file-organizer
pip install -r requirements.txt
python app.py
```

Then open:

http://127.0.0.1:5000
